## Usage

```
make            # compile ./run
make test       # run the examples of main.c
./run n0 r0   # one run with given parameters
make wp         # prove the contract with Frama-C/WP (alt-ergo, z3)
make wp-unproved   # only the verification conditions not proved (hypotheses, goal)
make wp-list    # one line per verification condition not proved
make wp-report  # status of every property in vc.csv, prints those not proved
make wp-print   # text of every verification condition
```

The input arrays are filled by `main.c` (expression in `i`, see `run`); edit
it, or regenerate the kit with `--kit-array NAME=EXPR` and `--kit-input`.
